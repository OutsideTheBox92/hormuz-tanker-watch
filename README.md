# Hormuz Tanker Watch

Interaktiv lägesbild över utvecklingen i och omkring Hormuzsundet, med fokus på råoljetankers och möjlig påverkan på Okeanis Eco Tankers.

## Filer
- `index.html` – visuellt gränssnitt och Leaflet-karta
- `events.js` – händelsedata som uppdateras när nya relevanta nyheter verifieras

## Källprincip
Bekräftade uppgifter prioriteras från Reuters och UKMTO. Maritim marknadsdata kompletteras med etablerade branschkällor. Ej oberoende verifierade uppgifter märks tydligt. Incidentpositioner är ungefärliga när exakt koordinat inte publicerats.

## GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)`.

Sidan använder Leaflet och OpenStreetMap-kartor via CDN.
